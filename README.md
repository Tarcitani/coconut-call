# Coconut

Aplicativo open source de chamadas de voz (individuais e em grupo, até 15 pessoas) e compartilhamento de tela para Windows 11, com mídia ponto a ponto via WebRTC. Em desenvolvimento inicial — veja [docs/status.md](docs/status.md).

**Privacidade:** a mídia trafega diretamente entre participantes, por isso cada participante vê o endereço IP dos demais.
